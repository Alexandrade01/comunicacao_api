## Endpoints da Aplicação
- **POST /comunicacao/agendar**: Agenda uma nova comunicação para o usuário.
- **GET /comunicacao/**: Busca o status de uma comunicação específica do usuário.
- **PUT /comunicacao/cancelar**: Cancela uma comunicação específica do usuário..
- **DELETE /comunicacao/enviar-email**: Envia um email para o destinatário especificado.
